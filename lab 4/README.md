# Artificial Intelligence Practicals

This repository contains four Python-based implementations of fundamental Artificial Intelligence concepts, focusing on knowledge representation, semantic relationships, and rule-based expert systems.

## Practicals Included

### 1. Frame Representation
- Implements Frame Representation using Python dictionaries.
- Represents real-world entities such as Students, Teachers, and Courses.
- Stores information in slots and their corresponding values.
- Provides options to display all frames and search for a specific frame.

**Concept:** Frame-Based Knowledge Representation

### 2. Medical Knowledge Representation
- Implements a simple rule-based medical expert system.
- Accepts symptoms entered by the user.
- Matches symptoms against predefined medical conditions.
- Identifies possible conditions based on the number of matching symptoms.
- Displays matching results with a medical disclaimer.

**Concept:** Rule-Based Expert System

### 3. Semantic Network Construction
- Constructs a semantic network using Python dictionaries.
- Represents entities such as Students, Teachers, Courses, and Universities.
- Establishes relationships such as `is_a`, `studies`, `teaches`, and `works_at`.
- Allows users to display the semantic network and search relationships.

**Concept:** Semantic Network Representation

### 4. University Knowledge Base
- Creates a knowledge base containing student, teacher, and course information.
- Stores student details using unique student IDs.
- Provides student search functionality.
- Displays teacher information and available courses.
- Uses Python dictionaries for knowledge storage and retrieval.

**Concept:** Knowledge-Based System

## Installation

Make sure Python 3 is installed on your system.

**No external libraries are required.** All programs use Python's built-in features.

## How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd Artificial-Intelligence-Practicals
```

Run individual programs:

```bash
python "Frame Representation.py"
```

```bash
python "Medical Knowledge Representation.py"
```

```bash
python "Semantic Network Construction.py"
```

```bash
python "University Knowledge Base.py"
```
